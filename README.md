# سنترال - نظام إدارة الأقساط واليومية ومحافظ الكاش (Central Management System)

نظام سحابي متكامل لإدارة السنترال والمبيعات ومتابعة أقساط العملاء وحركة الخزينة والدرج ومحافظ الكاش الإلكترونية (فودافون كاش وغيرها) وماكينات الدفع (فوري، أمان، بساطة).

## 🚀 المميزات الأساسية
- **سحابي متصل بقاعدة بيانات Supabase (PostgreSQL)**
- **متجاوب بالكامل:** يعمل على الكمبيوتر (Desktop) والهاتف المحمول (Mobile)
- **إدارة عملاء الأقساط:** تسجيل العقود، جداول السداد، تتبع المتأخرات والمتبقيات
- **دفتر اليومية والدرج:** تسجيل حركة النقدية الصباحية والمسائية، الوارد والمنصرف، والمصروفات
- **محافظ الكاش:** تتبع أرصدة خطوط الكاش وعمليات السحب والإيداع وحساب العمولات لحظياً
- **ماكينات الدفع الإلكتروني:** رصد أرصدة ماكينات فوري، أمان، بساطة

## 🛠️ التقنيات المستخدمة
- **Frontend:** React + Vite + TypeScript + Lucide Icons
- **Backend & Database:** Supabase (Cloud PostgreSQL)
- **Deployment:** Cloudflare Pages
